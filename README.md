## ファイルと使い方 / 文件与使用方法

- `miaoge_fenghuang_latest.html`：音声、注釈データ、知識解説、原PDFを埋め込んだ単体HTML。ブラウザで開くと閲覧・再生できる。初回の語・句クリックでは音声の準備に少し時間がかかる場合がある。
- `README.md`：使用方法、出典、編集方針。
- `miaoge_fenghuang_latest_bundle.zip`：HTMLとREADMEの配布用セット（EAFは含めない）。

HTML文件已嵌入音频、标注和知识内容，下载后可直接用浏览器打开。首次点击播放时可能需要等待音频解码。点击句子播放整句，点击词语播放该词；到所选区间终点自动停止。点击另一处会停止上一段。主音频控件可播放全段。英文词义显示在各词下，TE为英文句译。

日文句訳・中文句訳は対応する歌句の下に表示する。英語の語釈は語ごとに、TEは句ごとに表示する。言語表示、検索、要確認のみの絞り込み、速度変更が可能。速度を変更すると現在の選択片段は停止し、再クリックで変更後の速度になる。

Chrome、Edge、Firefox、SafariなどWeb Audio API対応ブラウザを想定。HTML内の「音声変更」はローカル再生であり、ファイルをアップロードしない。EAFはダウンロード提供しない。HTMLには表示・再生用の注釈データを含むが、元のEAFファイルは含めない。原PDFへのリンクはPDFデータを埋め込んでいるが、ブラウザによって新規タブでのdata URL表示が制限される場合がある。オンライン版の原PDFリンクは通常のファイルリンクである。

## 編集方針 / 编辑原则

最新アップロードの内容を基礎に、すでに承認された日本語修正47枠を反映し、知識解説13項目の推奨訳を使用。「頂真」はしりとりに似た語句反復であることを説明する。中文・英語の既存注釈は原則保持する。今回のEAFにある転写の更新（例：Niaxの句頭表記）を採用した。

原文と訳文・逐語釈が一致しない部分、植物名・地名・文化語等は要確認の訳注を別表示する。未注釈の句訳は推測で補わない。歌の意訳と語ごとの逐語釈は別の翻訳層であり、両者を無理に同一化しない。日訳修正は中国語資料との対照に基づき、苗語音声からの独立した再翻訳ではない。

時間スロット、語枠、注釈IDを保持。中国語・日語・英語の句層が独立している部分は、同じ声部で時間が最も重なる句を表示上対応させる。語は同じ声部の歌句へ時間の重なりで帰属させ、英語の語釈はEAFのANNOTATION_REFで直接対応させる。

表示には144件の非空苗文句枠、894語枠を収録。うち1句枠は原資料で中文・日文・TEが未注釈。対応音声の全長は約451.51秒。音声と意味の対応の精度は元のELAN標注を継承する。
